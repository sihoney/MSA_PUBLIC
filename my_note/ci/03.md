# CICD에서 매일 쓰는 쉘 + Github Actions 핵심 문법

---

## 전체 코드 먼저 해석

> "이미지 경로 + 태그 만들어서 다음 step에서 쓰려고 환경변수로 저장하는 코드"

```bash
echo "IMAGE_REGISTRY=ghcr.io/${GITHUB_REPOSITORY_OWNER,,}" >> "${GITHUB_ENV}"
echo "IMAGE_TAG=${GITHUB_SHA::7}" >> "${GITHUB_ENV}"
```

- 환경 변수 2개 생성
- 이후 step에서 계속 사용
---

```yaml
IMAGE_PATH="${REGISTRY}/$(echo "${IMAGE_NAME}" | tr '[:upper:]' '[:lower:]')"
echo "image=${IMAGE_PATH}:${IMAGE_TAG}" >> "$GITHUB_OUTPUT"
echo "latest=${IMAGE_PATH}:latest" >> "$GITHUB_OUTPUT"
```

- 이미지 경로 만들고
- 결과를 다음 step에서 쓰도록 export

---

## 이제 중요한 문법 하나씩

### 1️⃣ ${GITHUB_REPOSITORY_OWNER,,}

```bash
${변수,,}
```

- 의미: 소문자로 변환

예:

```bash
OWNER=SIHONEY

echo ${OWNER,,}
```

결과:

```bash
sihoney
```

---

왜 쓰냐?

- Docker/GHCR는 대문자 허용 안 하는 경우 많음

---

### 2️⃣ ${GITHUB_SHA::7}

```bash
${변수::길이}
```

- substring (문자 자르기)
- 앞에서부터 n글자만 가져옴

예:

```bash
GITHUB_SHA=abc123456789

echo ${GITHUB_SHA::7}
```

결과:

```bash
abc1234
```

--- 

왜 쓰냐?

- Docker tag로 짧게 쓰려고

```bash
ghcr.io/sihoney/apigateway:abc1234
```

---

### 3️⃣ >> "${GITHUB_ENV}"

```bash
echo "KEY=VALUE" >> $GITHUB_ENV
```

- Github Actions 전용 핵심 문법
- 다음 step에서도 쓸 수 있는 환경변수 등록

예:

```bash
echo "HELLO=world" >> $GITHUB_ENV

echo $HELLO
```

결과:

```bash
world
```

---

### 4️⃣ echo

- 그냥 출력 + 파일 쓰기용

```bash
echo "hello"
```

출력

```bash
echo "HELLO=world" >> file.txt
```

파일에 추가

---

### 5️⃣ >> (이거 중요)

- 파일에 추가 append

| 문법   | 의미    |
| ---- | ----- |
| `>`  | 덮어쓰기  |
| `>>` | 뒤에 추가 |

---

### 6️⃣ $( ... )

- 명령어 실행 결과를 값으로 사용

```bash
echo $(date)
```

- date 실행 결과가 들어감

---

### 7️⃣ tr '[:upper:]' '[:lower:]'

- 문자열 대문자 -> 소문자 변환

```bash
echo "HELLO" | tr '[:upper"]' '[:lower:]'

hello
```

---

### 8️⃣ | (파이프)

```bash
echo "HELLO" | tr ...
```

- echo 결과 -> tr로 전달

## 지금 단계에서 중요한 포인트

- CI/CD에서 값 전달 구조를 이해하는 단계

| 저장 위치            | 용도              |
| ---------------- | --------------- |
